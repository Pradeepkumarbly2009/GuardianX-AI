# GuardianX AI

## AI-powered Smart Accident Detection & Emergency Response Platform

GuardianX AI is an intelligent system that automatically detects road accidents and instantly notifies family members, ambulance services, and police with the victim's live GPS location.

### Features
- Automatic Accident Detection
- Live GPS Tracking
- Family Alerts
- Ambulance Notification
- Police Notification
- AI Crash Severity Detection (Coming Soon)
